# H O P P E R — Aventura Sin Fin

Un juego de móvil hecho con HTML5 Canvas. Controla a tu Hopper: salta los obstáculos del suelo y agáchate bajo las ramas para sobrevivir el mayor tiempo posible.

## Cómo jugar

- **Toca** para saltar (mientras estás en el piso)
- **No hagas nada** para agacharte bajo las ramas
- Cuantos más metros recorras, más rápido se pone el mundo

## Características

- Ciclo de día/noche con amanecer y atardecer
- Obstáculos naturales: troncos en el suelo y ramas en el techo
- Animación completa del Hopper con física de salto
- Historia secreta tras varias partidas 🦫

## Tecnología

Un solo archivo `index.html` — sin frameworks, sin dependencias externas. Puro Canvas 2D.
